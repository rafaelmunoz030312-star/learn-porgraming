APLICÁ LO APRENDIDO

Proyectos simples

Elegí un desafío, escribí el código en VS Code y marcá el proyecto al terminarlo.

01

Crear un botón

Creá un botón que cambie de color cuando pasás el mouse encima.

  • Usá <button>
  • Agregá colores con CSS
  • Probá :hover
02

Hacer una tarjeta

Diseñá una tarjeta de perfil con una imagen, nombre y descripción.

  • Usá <div> y <img>
  • Agregá bordes redondeados
  • Elegí tus propios colores
03

Crear un contador

Hacé botones para sumar y restar un número con JavaScript.

  • Creá dos botones
  • Usá una variable let
  • Actualizá el número en pantalla
04

Formulario de contacto

Armá un formulario para que una persona escriba su nombre y mensaje.

  • Usá <input> y <textarea>
  • Agregá etiquetas claras
  • Validá que no queden campos vacíos
05

Mini calculadora

Creá dos campos numéricos y un botón que sume sus valores.

  • Usá dos <input>
  • Leé los valores con JavaScript
  • Mostrá el resultado en pantalla
06

Lista de tareas

Hacé una app sencilla para agregar y tachar tareas pendientes.

  • Escribí una tarea en un campo
  • Agregala a una lista
  • Marcala al completarla
